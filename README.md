# The Alchemist's Legacy Shared

A Unity 2021.3.42f1 project for our group game prototype. This repository contains the cleaned shared version of the project, the Level 0 tutorial scene, and the asset packs we are currently using as development materials.

## Quick Start

1. Clone this repository.
2. Open the folder in Unity Hub.
3. Use Unity version `2021.3.42f1`.
4. Open `Assets/_TheAlchemistsLegacy/Scenes/Level0.unity`.
5. Press Play to test the tutorial level.

The first time Unity opens the project, it may take several minutes to rebuild the local `Library` folder. That folder is generated by Unity and is not uploaded to GitHub.

## Main Project Files

- `Assets/_TheAlchemistsLegacy/Scenes/Level0.unity`: tutorial level.
- `Assets/_TheAlchemistsLegacy/Scenes/TrailComplete.unity`: completion screen after the level.
- `Assets/_TheAlchemistsLegacy/Scripts/`: scripts written for our game.
- `Assets/_TheAlchemistsLegacy/Docs/GameDesignDocument.md`: current design notes.
- `Assets/`: imported asset packs and shared materials.

## Current Level 0 Flow

The player starts in a locked workshop trial. They read the master's note, collect two stamps, place them into the matching bowls, wait for the fire barrier to disappear, and then leave through the exit door. Completing the level loads the Trial Complete scene.

## Contributing

Before you start working:

```bash
git pull
```

After making changes:

```bash
git status
git add <changed-files>
git commit -m "Describe your change"
git push
```

Please avoid committing Unity-generated folders such as `Library`, `Temp`, `Logs`, and `UserSettings`. They are already ignored by `.gitignore`.

## Team Notes

- Keep our own gameplay code inside `Assets/_TheAlchemistsLegacy/Scripts/`.
- Keep our own scenes inside `Assets/_TheAlchemistsLegacy/Scenes/`.
- Do not directly copy old game logic unless we understand and adapt it for our design.
- If two people need to edit the same scene, communicate first because Unity scene files are hard to merge.
